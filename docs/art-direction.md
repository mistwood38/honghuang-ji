## 实现约定

- `visuals.ts` 只按既有 scene/place ID 选择原画与氛围，不进入存档。场景 override 优先，地点映射次之，未知地点回退山河原画。
- `art.tsx` 统一 picture 响应式素材、按需加载、固定画幅和纯装饰大气层。当前页面首图优先加载，其余懒加载。
- 云气、天光、三枚灵光与符文只使用少量 CSS 合成层，没有 Canvas 循环、外部动画库或大规模粒子。
- 开天/紫霄使用金光与三音铜磬，不周/补天使用暖色天光与低音铜鸣；一般抉择为短音。音效只从用户操作触发，关闭时不创建声音。
- 系统减少动态效果会关闭全站动画、过渡和装饰漂移；手机入世首图固定约 214px，故事与抉择正常纵向滚动；底栏预留安全区。
- 纸本阅读条允许跳至抉择或回看剧情，只移动滚动与焦点；未开始、文本输入、弹窗和非入世页面均拦截剧情数字快捷键。六相属性条按原引擎上限显示，数值不变。
- 抄录和轮回使用既有 Radix 弹窗，支持焦点圈定、Escape、关闭后焦点恢复；剪贴板不可用时提供手动选取全文。
- 地图点选只更新组件局部状态；小说仅更新原 `novelIndex`；筛选、字号、目录状态均不扩充存档。
