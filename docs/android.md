# 洪荒纪 Android 安装包

网页版仍在原来的入口。安装包是另外打出来的纯客户端，剧情、图片、字体和音效都在包里，不靠打开网页。

## 安装

1. 在手机浏览器打开这次构建：[Android APK 运行记录](https://github.com/mistwood38/honghuang-ji/actions/runs/41571014402)。需要登录 GitHub。在页面底部下载 `honghuang-ji-debug`，解压得到 `app-debug.apk`。
2. 以后每次推到 `art/stage-two-cinematic` 都会重新打一个测试包，入口在仓库的 Actions 里，工作流名叫 Android APK。
3. 允许浏览器或文件管理器安装未知来源的应用，点安装。桌面图标是朱印「洪」。
4. 这是个人测试用的 debug 签名，不是应用商店的正式包。没有发布到应用商店，也没有合并 main。

## 离线

故事、图、字和合成钟声都在安装包内。第一次打开不需要账号，也不下载剧情。

系统仍要求网络权限，因为 Android 的 WebView 用本机的 `https://localhost` 读取包内文件。应用没有远程服务器。是否在飞行模式下也能玩，要在真机或模拟器上再确认一次。

## 存档

进度写在这个安装包自己的存储里。关掉再打开还在。

网页里的存档不会自动进来。在网页的封面或「我的」里打开「存档搬移」，导出文本；在安装包的同一处粘贴并导入。两边互不覆盖，除非你亲手导入。

## 返回和后台

返回键先关掉正在看的人物或对话框。在山河、天书、本纪、我的里，回到入世。在入世里回到封面。在封面里把应用收到后台，不删进度。切到后台时钟声停下，回到前台时，若你本来开着钟声并且已经点过一次，会继续。

## 还没在手机上做过的事

打包机已经编出 `app-debug.apk`（约 13 MB），包名 `app.honghuang.ji`，应用名「洪荒纪」，包内有 62 张图、中文字体和游戏脚本。

模拟器启动了两次，都在进系统前被杀掉（退出码 137），设备一直停在 offline，所以没有完成安装、点选、听声、关闭重开和飞行模式。这些要等你用自己的手机装上之后才能算数。构建成功不等于这些功能已经在手机上验证过。
