# 体验收尾：乐声、阅读位置、器物

基于 `art/stage-two-cinematic`。不改剧情、数值、存档格式，也不改 Android 工程本身。网页和离线包都从 `public/audio` 读同一批文件。

## 乐声

十一段互不相同的床乐，按界面或场景情绪切换，约 1.1 秒交叉淡入。静音不会创建 AudioContext。切后台、安卓暂停沿用原来的 `pauseAmbience` / `resumeAmbience`。主要按钮在乐声开启时有短促击木，抉择是拨弦。

## 阅读

选择前不再显示「道行 +12」这类精确增减。落子之后，新正文上方出现「因果已揭」，才写出实际变化、得到或失去的器物。

页面不再在换幕时滚到最顶。锚点算在顶栏和「因果正文」条之下，所以先看见结果和后续句子，而不是封面大图。

## 器物

九件器物各自一张可点开的卡片。详页里的动效按物性分开：混沌对绕、骨裂、紫气上浮、剑芒横掠、血滴、钟波、息壤自下生长、天柱折断、香火与烟。没有统一旋转。

## 还不是开放修仙

这一轮没有加新系统。现有玩法仍是一条写死的场景图：选项把你送到下一幕，六项属性和器物只决定哪些门开着、结局落在哪一卷。所以它读起来仍像一篇不短的互动小说，而不是可以自己过日子的洪荒。

若以后要做成开放修行，缺的是这些，而不是再多几个空按钮：

- 同一地点可以反复做的事：吐纳、游历、寻人、劳作，而不是点完就离开
- 时间自己往前走，大劫按年景到来，不由「下一幕」触发
- 地图真正改变你身在何处；现在山河只是图鉴
- 人物关系、门派职位、香火是会变的状态，不只是一次性旗标
- 战斗或角力有来回，而不是一句选项结算
- 失败可以养回来，不必直接进入结局

本地另有未推送的 `play/open-world` 草稿，那是另一次尝试，没有并进这条分支。

## 验证

浏览器在 320、360、412 宽测过：选择钮上没有预先写明的属性差额；点「扑上斧脊」后停在「因果已揭」和下一幕正文，不再回到 scrollY 0。九件器物的详页能打开。十三首音频文件均可从 `/audio/` 取到。静音路径的单测确认不会创建音频上下文。

尚未在真机上听完整曲，也没有重新打包安装 APK。劫难曲只有约七十秒，循环时能听出接头。
