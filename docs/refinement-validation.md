# 第二轮完善与验收

日期：2026-11-03。延续 `art/primordial-rebuild` 与 PR #1；不合并 main、不发布正式版本。第一轮 `7cfa72a` 与原 main 的前后对照保留不动，本文件记录后续完善。

## 实际新增与修正

- **六张地域专属原画**：血海、东海扶桑妖庭、人族火塘、女娲炉火、蓬莱、幽冥。分别提供 1440×810 / 768×432 本地 WebP，总资源由六幅增至十二幅、二十四个 WebP，约3.5MB；单张新手机图约50–91KB。
- **场景区分**：血海、妖庭、娲皇与守火相关剧情、山河地志，以及本纪妖庭/造人/补天/薪火篇使用对应原画；补天不再沿用断裂天柱的画面。不同地域使用暖焰、海气或静谧氛围。
- **长剧情定位**：纸本阅读条可“前往抉择”，抉择区可“回看剧情”，同时移动焦点和滚动；手机画幅减至196px。跳转不选择选项、不改变属性或所至。
- **手机古籍**：压缩目录、扉页和章头间距，保留正文17px与长文行距。390×844下第一段正文在约542px处开始，较上一轮更早进入阅读；章末支持回到已展开的目录。
- **检索可见性**：天书正文与标题匹配高亮，搜索时自动展开匹配篇章；清除搜索恢复此前卷册展开状态，不修改原文。
- **弹窗与抄录**：复用已有Radix依赖，支持焦点圈定、Escape、滚动锁与关闭后的焦点恢复；轮回初始焦点为“留下”。剪贴板缺失/拒绝时显示准确反馈，并提供“选取全文”；抄本文字仍来自原 lifeText。
- **快捷键修复**：原界面在“尚未入世”按1也会偷偷加属性并改变sceneId。现仅在已开始且当前仍为入世时响应；输入框、选择框、可编辑正文、弹窗、组合输入与按键重复均不触发剧情快捷键。
- **六相显示修正**：属性条按原引擎400/160/160/160/100/100上限绘制，替换原160/80/80/80/80/100的显示比例；属性数值、成长和规则不变。

## 浏览器验证

可复现命令（开发服务已启动）：

```bash
node --experimental-strip-types scripts/art-browser-qa.mjs http://127.0.0.1:8080/ screenshots/refinement --refinement
```

生产构建可用 `npm run preview:restart` 启动，再将目标换为8081、截图目录换为 `screenshots/refinement-production`。

`--refinement`仍执行第一轮完整三视口流程：新游戏、道号/根骨、鼠标/数字键选择与引擎计算对比、六页切换、阅读章节、地图不移动、音效保存、真实v1旧档逐字段恢复、减少动态效果、完整证道与轮回归档。另增加390×844、320×740、844×390的专项验证：

- 未开始或在表单/弹窗中按数字，存档没有任何变化。
- 阅读与抉择定位后标题可见、焦点正确、导航可达，数据不变。
- 轮回安全初始焦点、Tab圈定、Escape取消与触发按钮焦点恢复。
- 剪贴板不可用时显示手动路径；选取区间完整覆盖原抄本文字。
- 手机正文起点、回目录、搜索自动展卷/高亮/清除恢复。
- 六相都在真实上限50%时，显示条均为50%，数值保持原样。
- 六个地域逐一选择不同本地原画，检查真实解码尺寸；地点浏览不改变剧情。

开发版结果：[verdict.json](../screenshots/refinement/verdict.json)。生产构建结果：[verdict.json](../screenshots/refinement-production/verdict.json)。全页截图仅在采集阶段加载屏幕外图片；游戏继续按需加载。
